# 智能惠农信贷系统 —— 测试用例清单

> **当前架构（后端驱动）**：前端数据全部来自 Spring Boot 后端（`smart-agri-loan-server`，Spring Security + JWT + H2/MySQL），
> 现行联调用例见 `tests/e2e-integrated.spec.js`（TC-I01 ~ TC-I09）。
>
> 下文的 TC-01 ~ TC-25 属于**第一阶段「前端本地 localStorage 数据池」时代**的用例，
> 其自动化脚本已归档至 `tests/legacy/e2e.spec.js`（由 `playwright.config.js` 的 `testIgnore` 排除），
> 仅作设计过程留档 —— 其中「模拟签约 / 模拟放款 / 数据池污染容错」等场景在后端架构下已不适用。

## 〇、后端驱动架构联调用例（现行）

运行前提：
1. 启动后端：`cd smart-agri-loan-server && mvn spring-boot:run`（默认 8080，H2 内存库，启动时重建种子数据）
2. 启动前端静态服务：前端项目根目录执行 `python -m http.server 8090`
3. 执行用例：`BASE_URL=http://localhost:8090 npx playwright test --config tests/playwright.config.js`

| 编号 | 用例标题 | 覆盖点 |
| --- | --- | --- |
| TC-I01 | 未登录访问「我的申请」被拦截到登录页 | 前端路由守卫 + 鉴权 |
| TC-I02 | 农户登录后导航按角色显隐，首页展示信用自适应卡片 | JWT 登录 / 角色菜单 / 自适应 |
| TC-I03 | 产品页准入提示由后端按信用等级下发 | canApply / applyTip 由后端计算 |
| TC-I04 | 审批人员打开产品页：不可申请 | 角色权限（审批岗不参与申贷） |
| TC-I05 | 信用页数据来自后端：积分、等级、五维、权益与授信政策 | `GET /api/credit/me` 全字段 |
| TC-I06 | 注册新农户并提交贷款申请写入数据库 | 注册接口 + 申请落库（多步表单） |
| TC-I07 | 审批端初审通过并写入流转日志 | 审批流 + 状态流转日志 |

| TC-I09 | AOP 操作日志可查询，且农户越权访问被拒 | AOP 操作日志 + 越权拦截 |

> 说明：TC-I06 ~ TC-I08 使用**每次运行唯一注册**的新农户账号（初始 660 分 / A 级），而非种子账号 `farmer`。
> 原因是业务闭环会把种子账号积分由 762 改为 767，导致用例无法重复执行（详见 `e2e-integrated.spec.js` 顶部注释）。

## 二、用例明细

### TC-01 首页加载
- 前置：数据池已灌入种子数据
- 步骤：打开 `/index.html`
- 预期：统计卡 4 张；热门产品卡片 3 张；办理流程 4 步；最新资讯 3 条；无控制台报错

### TC-02 产品卡片自定义属性
- 步骤：打开 `/pages/products.html`
- 预期：渲染 6 张产品卡片，每张卡片存在 `data-product-id` 属性（如 P001~P006）

### TC-03 产品筛选
- 步骤：点击"政策贷"类型标签
- 预期：列表仅剩政策贷产品（2 款），筛选结果计数同步更新

### TC-04 产品详情弹窗
- 步骤：点击卡片"详情"按钮 → 点击关闭
- 预期：弹窗展示额度/期限/担保/适用对象，关闭后弹窗消失

### TC-05 / TC-06 资讯
- 步骤：打开 `/pages/news.html`，切换"政策解读"分类，点击首条标题
- 预期：分类切换后条数为 2；点击标题弹出详情弹窗且正文段落数 > 1

### TC-07 信用积分
- 步骤：打开 `/pages/credit.html`
- 预期：仪表盘 `stroke-dashoffset` 大于 0；雷达图区域 5 个顶点；积分日志 6 行

### TC-08 多步骤表单切换
- 步骤：填写第一步合法数据后点"下一步"，再点"上一步"
- 预期：步骤条在 1/2/3 之间正确切换，按钮文案随步骤变化

### TC-09 必填项留空（异常）
- 步骤：未选择产品直接点"下一步"
- 预期：停留在第一步，出现"请选择贷款产品"错误提示，不进入第二步

### TC-10 身份证校验（异常）
- 步骤：第二步输入 `110105194912310021`（校验位错误）后点"下一步"
- 预期：提示"身份证号校验位不通过"，不进入第三步；改为 `11010519491231002X` 后通过

### TC-11 手机号校验（异常）
- 步骤：输入 `12345` 后点"下一步"
- 预期：提示"手机号格式不正确，请输入 11 位手机号"

### TC-12 金额校验（异常）
- 步骤：选择"惠农e贷·春耕贷"，输入 `500` 后点"下一步"
- 预期：提示"申请金额需在 10,000 ~ 300,000 元之间"

### TC-13 正常提交
- 步骤：三步全部填写合法数据，勾选两项授权，点击"确认提交申请"
- 预期：生成 `SQ` + 日期 + 时间戳 + 随机数的唯一编号；跳转 `apply-result.html?id=xxx`；数据池新增一条状态为"待初审"的申请单

### TC-14 反馈页
- 预期：展示申请编号、产品、金额、期限、状态标签；进度条当前步为"提交申请"

### TC-15 ~ TC-18 审批台
- 步骤：打开 `/pages/audit.html`，对目标申请单执行通过/拒绝
- 预期（通过）：状态变为"初审通过"，记录审批时间与审批人，追加流转日志
- 预期（拒绝空意见）：提示"拒绝申请必须填写审批意见"，状态不变
- 预期（拒绝）：填写意见后状态变为"已拒绝"

### TC-19 风控看板
- 步骤：在审批台打开任一申请单详情
- 预期：展示申请人信用积分；风险等级标签为低/中/高风险（≥750 绿、650~749 黄、<650 红）

### TC-20 模拟签约
- 步骤：进度页对"初审通过"的单据点击"模拟签约"
- 预期：状态变为"已签约"，进度条第三步点亮为青色，出现"模拟放款"按钮

### TC-21 模拟放款
- 步骤：点击"模拟放款"
- 预期：状态变为"已放款"；用户账户余额 = 原余额 + 申请金额；出现"模拟还款"按钮

### TC-22 余额不足（异常）
- 前置：将用户账户余额置为 0
- 步骤：点击"模拟还款"
- 预期：还款被阻断，状态仍为"已放款"，页面提示"账户余额不足"并给出应还金额与差额

### TC-23 模拟还款
- 前置：将用户账户余额置为 100000
- 步骤：点击"模拟还款"
- 预期：状态变为"已结清"；余额扣减应还本息；信用积分 +5；积分变动日志首条为本次结清记录（+5）

### TC-24 响应式
- 步骤：视口切换为 390×844，依次打开首页、产品页、进度页、审批页
- 预期：页面无横向滚动（scrollWidth 不超过视口宽度），导航与卡片正常堆叠

### TC-25 数据污染容错
- 步骤：将本地存储数据池改写为非法字符串后刷新首页
- 预期：系统自动重建种子数据，页面正常渲染产品与统计信息
